# WordPress Elementor Development

A starting structure for WordPress and Elementor development:

- `elementor-templates/` — Elementor template exports (JSON).
- `css/` — Custom stylesheets.
- `js/` — Custom JavaScript.
- `components/` — Reusable component snippets and related assets.

A small [responsive hero template](elementor-templates/responsive-hero.json) and [Elementor import guide](elementor-templates/README.md) are included. The other folders are reserved for future work. No dependencies are installed.
